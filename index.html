How-To & Documentation

1. Traversal & Decoder

  1. Enter any string or emoji sequence in the input box.
  2. Choose a keyboard / matrix layout (QWERTY, emoji grid, TV keyboards, etc.).
  3. Optionally enable toroidal wrapping so the path can wrap around edges.
  4. The path updates live as you type. You can also click Run Analysis.
  5. Use Copy Path or Export CSV for further analysis.

2. Cipher Grouping & Blocks

  • Alphanumeric – keeps letters & digits, optionally strips everything else, uppercases, then groups.
  • Binary / Hex / Octal – converts each character to its code-point representation and groups the resulting digits.
  • Change Group Size live (classic sizes: 5, 4, 8, etc.).
  • Output updates instantly as you type.

3. Vertical Text Engine

  • Direct mode simply stacks the characters vertically using CSS writing-mode.
  • Katakana mode performs a simple phonetic transliteration of English syllables into Japanese katakana.
  • Choose traditional right-to-left column flow or modern left-to-right.

4. Floating Assistant

Click the floating panel in the bottom-right corner. You can evaluate math expressions (sin(45 deg), 0xFF + 12, etc.) or run a quick configuration audit.

5. Privacy

All processing happens locally in your browser. We do not upload or store the text you analyze. See our Privacy Policy.
